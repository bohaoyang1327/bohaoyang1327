Accepted for publication in *npj Digital Medicine*, this manuscript presents `MOSAIC`, a multi-agent framework for analyzing clinician-patient communication across multiple coding frameworks. The project combines retrieval-augmented generation, adaptive prompting, multimodal alignment, and human-in-the-loop evaluation to improve both coding accuracy and clinical usability.

[View the preprint on arXiv](https://arxiv.org/abs/2512.08659).
